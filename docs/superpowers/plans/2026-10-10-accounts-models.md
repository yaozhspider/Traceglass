# Accounts and model settings implementation

User-approved scope: open username/password registration, isolated users, personal OpenAI-compatible model configuration in the browser. Implement inline; no subagents. Preserve existing development services and data.

Architecture: optional deployment mode `TRACEGLASS_AUTH_ENABLED=true`; public deployments require Docker. SQLite stores accounts, password hashes, hashed expiring sessions and model defaults. HttpOnly cookies plus CSRF headers protect writes; authenticated server identity replaces X-User-ID on all allowed native and product routes. Restrict native HTTP surface to product-required routes; never expose user-controlled host MCP/skill configuration. Per-user analyst IDs and credential IDs avoid AgentScope SQL global-key collisions. Workspace ownership must be checked before cache lookup, including legacy bindings.
