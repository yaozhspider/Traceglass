# 混淆形态和分析选择

| 形态 | 重点证据 | 常用方法 |
|---|---|---|
| 控制流平坦化 | dispatcher、状态变量、重复间接跳转 | CFG、符号执行、D-810/SATURN 类方法 |
| 不透明谓词 | 恒真/恒假但复杂的算术条件 | SMT、路径约束、简化表达式 |
| MBA | 加减/XOR/乘法混合且可化简 | LLVM/P-code 归一化、代数化简 |
| 虚假控制流/死代码 | 不可达块或无副作用路径 | 可达性分析、CFG 清理 |
| 间接跳转/API 哈希 | 哈希循环、动态表、间接调用 | 解析表、模拟哈希、交叉引用调用点 |
| 字符串加密 | 常量 blob、解密 stub、运行时写入 | 追踪解密函数、FLOSS、动态 dump |
| 自定义 VM | opcode 分发器、寄存器数组、解释循环 | 提取 opcode 语义、构建 VM IR |
| 运行时解包 | 分配可执行内存、解压/解密后跳转 | 受控沙箱、解密后内存快照 |

不要因为代码复杂就判定为混淆；要给出形态证据和对业务逻辑的实际影响。
